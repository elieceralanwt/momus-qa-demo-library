# momus-qa-demo-library

A small library-lending system (books, members, loans, fines, reservations) written in Python.

This repository is **test data for [Momus QA](https://github.com/elieceralanwt/momus-qa)**. It holds issues and pull requests that follow the conventions in Momus QA's `standards/` folder, so that the tool has real input to run against end to end.

It is **not an evaluation set**. Its issues and pull requests are not a benchmark, are not labelled for measuring results, and must not be used to report Momus QA's performance.

## Conventions

- `.github/ISSUE_TEMPLATE/user-story.yml` is the issue form for stories, with Gherkin acceptance criteria.
- `.github/pull_request_template.md` is the pull request template, with the `Closes #<issue>` line.
- Issues carry the `story` label.
